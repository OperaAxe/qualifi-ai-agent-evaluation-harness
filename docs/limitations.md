# Limitations

This harness does not connect to an LLM provider and does not measure real model quality, token usage, cost, or provider latency. The demonstration agents are deterministic fixtures. The environment has a tiny tool surface and simplified authorization policy.

A future adapter could connect a real provider behind explicit configuration, but real credentials, provider costs, reproducible trials, and data-handling controls would then need to be documented. A real-model benchmark claim requires actual provider-backed executions and evidence.
