# References

- Anthropic, “Demystifying evals for AI agents” — https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents
  - Relevant principles used here: combine code-based graders with other grader types when needed; separate capability and regression evals; isolate trials; use unambiguous tasks and reference solutions; prefer outcome checks over brittle tool-path checks; expose partial failure dimensions.
- OpenAI, “Practices for governing agentic AI systems” — https://openai.com/index/practices-for-governing-agentic-ai-systems/
  - Consulted as a general reference for treating agent actions, tool permissions, and observability as explicit system concerns.

These references inform the repository’s design. They are not evidence that this local deterministic fixture evaluates any particular commercial model.
